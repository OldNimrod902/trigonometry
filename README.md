# Trigonometry calculator (and more)

The code is written in C++ and doesn't use platform specific features.



You can do the following in the app:



1. *Solve a triangle*
2. Calculate its **area**
3. Calculate its **median**, **angle bisector**, etc.
4. Calculate the **radius** of a **triangle's circumcircle** and **incircle**
5. **BONUS: it's up to you, if you'd use degrees or radians - both are availible**

Along these trigonometric features, you can also ***find the Pythagoream Theorem***, and ***a basic Sin and Cosine value calculator***



You can navigate the app using **numbers** from your keyboard
